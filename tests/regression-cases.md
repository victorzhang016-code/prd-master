# Regression Cases

Use these cases to sanity-check the canonical package after edits.

## Rich-context cases

1. Bonnie real-time recommendation PRD
   - Expect full discovery or reuse of existing context
   - Expect explicit assumptions and acceptance criteria
2. Privacy-mode PRD
   - Expect ambiguous definitions to be surfaced, not silently guessed
3. Launch spec with known metrics
   - Expect measurable goals and a recommendation

## Sparse-context cases

4. "我想做一个创作者成长功能"
   - Expect discovery first, not immediate drafting
5. "帮我整理成 PRD"
   - Expect identification of product, target user, trigger, and success metric gaps

## Constraint-heavy case

6. "一周内上线，后端只给一个接口窗口"
   - Expect scope cuts, explicit tradeoffs, and execution-aware acceptance criteria
